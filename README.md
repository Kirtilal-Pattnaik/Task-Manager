# Task Manager

A simple Task Manager web application built using HTML, CSS, and JavaScript. Users can add tasks, mark them as completed, delete tasks, and track task statistics.

## Features

- Add new tasks
- Display task list
- Mark tasks as completed
- Delete tasks
- Dynamic updates without page reload
- Total task counter
- Completed task counter
- Responsive and user-friendly interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Project Structure

```text
Task-Manager/
│
├── index.html
├── style.css
└── script.js
```

## How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any web browser.

## Usage

1. Enter a task in the input field.
2. Click the **Add Task** button or press **Enter**.
3. Click a task to mark it as completed.
4. Click the **Delete** button to remove a task.
5. View the task statistics at the bottom.
